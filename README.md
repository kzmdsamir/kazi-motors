# Kazi Motors

Car-parts selling business for Bangladesh — Uttara Sector 15, Dhaka (near BRTA / Bridge 2).

A mobile-first web shop: searchable parts catalogue (price on request, the way the
Dhaka trade works), cart with WhatsApp ordering, cars for sale, and full
Bangla / English. Built with plain HTML, CSS and JavaScript — no build step.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
