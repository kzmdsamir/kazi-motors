# Kazi Motors

Car-parts web shop for Bangladesh.

A mobile-first online shop: searchable parts catalogue (price on request),
cart with WhatsApp ordering, cars for sale, and full Bangla / English.
Built with plain HTML, CSS and JavaScript — no build step.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
